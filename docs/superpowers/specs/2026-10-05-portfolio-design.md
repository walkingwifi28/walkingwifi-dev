# ポートフォリオの見た目の改善案

## 推奨する方向性
落ち着いたエディトリアル調。生成りの背景、墨色の文字、青緑のアクセントを使用する。装飾を増やしすぎず、余白と文字の強弱で洗練された印象をつくる。

## 具体的な変更
- 冒頭の walkingwifi を大きく表示し、氏名・所属を整ったプロフィール領域にまとめる。
- セクション見出しに小さな英語ラベルと細い区切り線を添える。
- 勤務歴を年と本文が読みやすいタイムラインに整える。
- 開発経歴は控えめな枠と背景を持つカードにまとめ、技術ロゴのサイズを調整する。
- 個人プロジェクトはクリック領域の広いカードとして配置する。
- スマートフォンでは一列に並べ、見出しと本文のサイズ・余白を調整する。

## 範囲と確認
既存のプロフィール、経歴、プロジェクト、リンク先を保持する。index.html と既存の assets を使い、ビルド不要の構成を維持する。PCとスマートフォンの表示、横はみ出し、キーボードフォーカス、リンク先を確認する。

## 比較した方向性
1. エディトリアル調（推奨）：読みやすさと上品さを両立する。
2. ダーク調：黒と鮮やかなアクセントで技術者らしさを強める。
3. カラフル調：色面や丸みを増やし、親しみやすさを強める。
